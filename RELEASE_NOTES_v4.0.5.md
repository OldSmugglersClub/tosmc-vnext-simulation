# Release Notes 4.0.5

Dieser Hotfix bereinigt den öffentlichen Spielerbereich. Technische Datenquellen-, Export-, Prüf- und Registerinformationen wurden aus der Highscore-Seite entfernt oder in verständliche Mitspielertexte umgewandelt. Ranglisten, Spielerprofile, Teamwertungen, Rekorde und mobile Darstellung bleiben erhalten.
