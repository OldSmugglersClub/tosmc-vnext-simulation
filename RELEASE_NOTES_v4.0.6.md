# Release Notes – Version 4.0.6

## Mobile Spieltagskachel

Version 4.0.6 korrigiert den Zeilenumbruch im Kopfbereich der Spieltagskachel auf schmalen Smartphone-Displays.

- Der Name des Tippspieltags nutzt unterhalb der Kopfleiste die volle verfügbare Breite.
- Lange Begriffe wie „Smugglerauftrag“ werden nicht mehr mitten im Wort getrennt.
- Das Statusschild hält kurze Angaben wie „1 SPIEL“ in einer zusammenhängenden Zeile.
- Desktop-Ansicht und Datenfunktionen wurden nicht verändert.
