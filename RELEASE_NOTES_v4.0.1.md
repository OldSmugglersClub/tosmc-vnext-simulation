# Release Notes – Version 4.0.1

## Änderung

Die Highscore-Kachel auf der Desktop-Startseite wurde innerhalb ihrer bestehenden Abmessungen gestalterisch aufgewertet. Messingdetails, eingelassene Holztafeln, vorhandene Piraten-SVG-Symbole und dezente dekorative Elemente reduzieren die zuvor große leere schwarze Fläche.

## Unverändert

- Mobile Highscore-Kachel
- dynamische Inhalte und IDs
- Link zur Highscore-Seite
- Kachelgröße, Raster und Abstände
- übrige Bereiche der Website

Es wurden keine neu generierten Bilddateien in die Website aufgenommen.
