# Version 3.7.1 – Mobile Highscore-Korrektur

Diese Wartungsversion behebt ausschließlich die fehlerhafte mobile Darstellung des Highscore-Teasers auf der Startseite. Texte überlagern keine benachbarten Karten mehr. Auf sehr schmalen Displays unter 360 Pixeln werden die drei Karten untereinander dargestellt.
