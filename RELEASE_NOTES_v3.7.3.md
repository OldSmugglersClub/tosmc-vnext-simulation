# Release Notes 3.7.3

Diese Wartungsversion korrigiert die mobile Highscore-Darstellung auf der Startseite. Die drei Werte erscheinen auf Smartphones als drei eigenständige, vollständig umrahmte Karten untereinander. Zusätzlich verhindert eine Versionskennung am Stylesheet, dass ein veralteter Browser- oder GitHub-Pages-Cache die Korrektur verdeckt.
