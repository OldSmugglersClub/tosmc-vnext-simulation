# Release Notes 3.9

## Zentrale Wettbewerbsverwaltung

Version 3.9 ergänzt eine lokale Pflegeoberfläche für das zentrale Wettbewerbsregister. Änderungen werden erst durch den manuellen Upload der exportierten `wettbewerbe.json` veröffentlicht.

Das freigegebene Website-Layout wurde nicht verändert.
