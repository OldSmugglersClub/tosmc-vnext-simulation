# Release Notes – Version 4.3.4

## Deckende Startzentrale

Der sichtbare Diskus beziehungsweise die diagonalen Linien stammten nicht aus einem verbliebenen HTML-Element. Die CSS-Regel aus Version 4.3.2 entfernte mit `background-image: none` unbeabsichtigt auch die eigenen Hintergrundverläufe der Startzentrale. Dadurch schien das großflächige Seitenhintergrundbild durch die Kachel hindurch.

Version 4.3.4 stellt einen vollständig deckenden dunklen Verlauf her und lässt alle alten Pseudo-Elemente deaktiviert.

Unverändert bleiben Kachelgröße, Inhalte, Statusfelder, Hauptbutton, Navigation und mobile Darstellung. Es wurden keine Bilder erzeugt oder verändert.
