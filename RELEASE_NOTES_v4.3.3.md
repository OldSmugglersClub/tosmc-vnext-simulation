# Release Notes 4.3.3

## Bonuswettbewerb

- Tippspieltag Nr. 1 ist der saisonbegleitende Bonuswettbewerb.
- 25 Fragen, je 5 Punkte, maximal 125 Punkte.
- Bonuspunkte fließen in die Gesamtwertung ein.
- Eigener Highscore-Tab und Hall-of-Fame-Eintrag ergänzt.
- Keine konkreten Bonusfragen erfunden; diese werden erst aus einem verlässlichen Datensatz übernommen.
