# Release Notes 3.19

## Spieltag-Einzelwertungen

Version 3.19 ergänzt eine getrennte Rangliste für jeden zentral erfassten Spieltag. Die Auswertung basiert auf `punkte.json`, `spieldaten.json` und `wettbewerbe.json`. Bonusfragen ohne eindeutige Spieltagszuordnung werden nicht in die Spieltagwertung eingerechnet.

Die Saison-Gesamtwertung, die Wettbewerbswertungen und das freigegebene öffentliche Layout bleiben unverändert.
