# Release Notes 3.13 – Automatische Highscore-Auswertung

Die öffentliche Gesamtwertung ist mit der zentralen Punkteberechnung verbunden. `punkte.json` hat Vorrang, sobald sie mindestens einen berechneten Ranglisteneintrag enthält. Die Seite zeigt die aktive Datenquelle ausdrücklich an und fällt andernfalls kontrolliert auf `highscore.json` zurück.

Das bestehende Highscore-Layout, die Teamansichten, Rekorde und mobilen Kachelgrößen wurden nicht verändert.
