# Release Notes – Version 3.3

Version 3.3 verbessert Bedienbarkeit, Barrierefreiheit und mobile Robustheit, ohne das freigegebene Erscheinungsbild zu verändern.

## Änderungen

- einheitliche sichtbare Tastaturfokusse
- Sprunglink zum Hauptinhalt auf Seiten ohne vorhandenen Sprunglink
- besser bedienbare breite Tabellen auf kleinen Displays
- Mindesthöhe wichtiger Touch-Bedienelemente
- 16-Pixel-Formularschrift auf Mobilgeräten gegen unerwünschtes Browser-Zoomen
- erweiterte Beachtung von Systemeinstellungen für reduzierte Bewegung und höheren Kontrast
- sichere Behandlung externer Links, die in einem neuen Tab öffnen

Es wurden keine Kachelgrößen, Raster, Abstände oder Navigationsstrukturen umgestaltet.
