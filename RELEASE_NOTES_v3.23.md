# Release Notes Version 3.23

Version 3.23 ergänzt eine lokale Erinnerungszentrale für fehlende Tippabgaben. Offene Tipps werden nach Teilnehmer gebündelt und als kopierbare Nachricht vorbereitet. Filter nach Zeitraum, Wettbewerb und Teilnehmername sowie JSON-, CSV- und Text-Export sind enthalten. Nachrichten werden nicht automatisch versendet.
