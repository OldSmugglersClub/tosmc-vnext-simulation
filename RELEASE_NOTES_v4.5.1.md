# Release Notes – Version 4.5.1

## Zweck
Verbindliche fachliche Definition des späteren Adminmoduls „Spieltag abschließen“.

## Kernaussage
Der Kicktipp-Export ist die verbindliche Wahrheit.

Fehlende Tipps:
- sind zulässig
- gelten als nicht abgegeben
- erhalten 0 Punkte
- blockieren die Berechnung nicht

## Nächste Voraussetzung
Eine echte Kicktipp-Exportdatei muss analysiert werden, bevor der Importparser entwickelt wird.

## Unverändert
- öffentliche Website
- lokales Adminsystem
- HTML
- CSS
- JavaScript
- JSON-Nutzdaten
