# Release Notes – Version 4.1.7

## Startzentrale bereinigt

Die in Version 4.1.5 zusätzlich über das vorhandene Kachelmotiv gelegten Schaltflächen wurden vollständig entfernt.

Die Willkommen-Kachel nutzt wieder ausschließlich die zwei bereits im Bild gestalteten Bedienflächen:

- **Zum Kicktipp**
- **Wettbewerbe ansehen**

Beide Bereiche bleiben über unsichtbare, exakt positionierte Klickflächen funktionsfähig. Dadurch entstehen weder auf dem Desktop noch in der mobilen Darstellung doppelte oder überlagerte Buttons.

Es wurden keine Bilder erzeugt, ersetzt oder verändert. Kachelgröße, Raster, Abstände und Navigation bleiben unverändert.
