# Release Notes – Version 4.4.5

## Zweck

Version 4.4.5 startet das **Smugglers Design System (SDS)** als eigenständiges, versioniertes Projektmodul.

## Neu

- verbindliche Bezeichnung **Schmugglersiegel**
- dokumentiertes Masterprinzip für eigene Vereinskennzeichen
- zentrale Ordnerstruktur für zukünftige SDS-Assets
- Größen-, Farb-, Kürzel- und Dateiregeln
- klare Pilot-, Serien- und Integrationsphasen
- verbindliche Rückbauregeln

## Wichtig

Diese Version enthält bewusst:

- keine generierten Bilder
- noch keine Mastergrafik
- keine Vereinssiegel
- keine Änderungen an öffentlichen Seiten

Der nächste Schritt ist die Entwicklung einer editierbaren Masterdatei als isolierter Prototyp. Erst nach Freigabe beginnt die Pilotserie.
