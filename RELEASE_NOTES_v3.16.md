# Release Notes 3.16

## Smugglerauftrag-Auswertung

Version 3.16 ergänzt eine separate, datengetriebene Auswertung der 34 Dynamo-Missionen. Die normale Einzel-Gesamtwertung bleibt unverändert.

### Neu

- Smuggler-Rangliste nach 2/3/5 Punkten
- Einzelprotokoll pro Auftrag und Teilnehmer
- Filter nach Auftrag und Teilnehmer
- JSON- und CSV-Export
- zentrale Datenquelle `smugglerpunkte.json`
