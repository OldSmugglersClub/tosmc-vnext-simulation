# Release Notes 3.25

## Abgabezuverlässigkeit und Teilnehmerstatus

Die neue lesende Verwaltungsseite wertet bestätigte und bereits abgelaufene Tippfristen je aktivem Teilnehmer aus. Vorhandene Tipps und das Erinnerungsprotokoll werden zusammengeführt. Spiele ohne bestätigte genaue Anstoßzeit werden nicht als Versäumnis gewertet.

Das öffentliche Layout und die bestehenden Kachelgrößen bleiben unverändert.
