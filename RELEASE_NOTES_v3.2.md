# Release Notes – Version 3.2

## Statistik- und Highscore-Erweiterung

Version 3.2 ergänzt den Bereich „Rekorde & Orden“ um eine belastbare Feldanalyse.

- Durchschnitt, Median, Punktespanne und Streuung
- Verteilung der gewerteten Spieler in vier Leistungszonen
- automatischer Bereitschaftsmodus, solange noch keine Punkte vorliegen
- keine simulierten oder geschätzten Statistiken
- keine Änderung an Grundlayout, Kachelgrößen oder Navigation
