# Release Notes 3.0.1

## Zweck

Version 3.0.1 bereinigt ausschließlich die Repository-Struktur. Das freigegebene Layout, die Kachelgrößen, Abstände, Navigation und Website-Funktionen wurden nicht verändert.

## Änderungen

- GitHub-fertige Paketstruktur: `index.html` liegt direkt im ZIP-Hauptverzeichnis.
- Alte versionsbezogene README- und Upload-Anleitungen entfernt.
- Nicht mehr referenzierte Zwischenbilder, Testdateien, ältere CSS-/JavaScript-Dateien und redundante Wettbewerbs-JSON-Dateien entfernt.
- Hauptdokumentation aktualisiert.
- Explizite GitHub-Änderungsliste ergänzt.
- Release-Audit und Manifest neu erzeugt.
