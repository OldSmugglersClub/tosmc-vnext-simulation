# Release Notes – Version 4.1.8

## Responsive Stabilisierung

Diese Version ist ein technisches Qualitätsupdate für die öffentliche Website.

### Änderungen

- Schutz vor horizontalem Überlaufen auf kleinen Displays
- stabile Einspaltenansicht für Wettbewerbe, Highscore und Hall of Fame
- kontrollierte Wortumbrüche ohne Trennung mitten im Wort
- flexible Buttons ohne Überlagerung anderer Inhalte
- keine Bilderstellung und keine Änderung vorhandener Bilddateien
- keine Änderung an Kachelgrößen, Grundlayout, Navigation oder Daten
