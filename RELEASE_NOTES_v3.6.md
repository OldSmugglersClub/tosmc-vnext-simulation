# Release Notes – Version 3.6

Version 3.6 erweitert das Administrationszentrum um ein ausschließlich lokal gespeichertes Pflegeprotokoll. Prüfstände lassen sich dokumentieren, vergleichen und als JSON exportieren. Die Wiederherstellungsprüfung kennzeichnet Sicherungen aus abweichenden Website- oder Datenversionen als kontrollpflichtig.

Es wurden keine Änderungen am freigegebenen Grundlayout, an Kachelgrößen oder an der Navigation vorgenommen.
