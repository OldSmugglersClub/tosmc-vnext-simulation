# Release Notes 3.4

Version 3.4 erweitert das bestehende Administrationszentrum um zwei Wartungsfunktionen:

- Konsistenzprüfung der zentralen Wettbewerbs-, Spiel-, Team- und Tippspieltag-Daten
- lokaler Export einer vollständigen JSON-Datensicherung

Die Sicherung verändert weder das GitHub-Repository noch die laufende Website. Das freigegebene Layout bleibt unverändert.
