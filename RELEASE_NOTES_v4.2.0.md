# Version 4.2.0 – Startzentrale der Crew

Die Willkommen-Kachel wurde als echte Navigationszentrale neu aufgebaut.

## Änderungen

- keine angeschnittene Plakette mehr am oberen Rand
- klare Begrüßung und Saisonkennzeichnung
- kompakter Statusbereich für Saison, nächste Mission und Champion
- zwei gleich breite, sauber ausgerichtete Schaltflächen
- echte HTML-Links statt unsichtbarer Klickflächen über einem Bild
- stabile mobile Einspaltenansicht
- keine Änderung an Kachelgröße, Raster oder Hauptnavigation
- keine Bilderstellung und keine neuen Bilddateien
