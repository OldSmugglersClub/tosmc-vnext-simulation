# Release Notes – Version 4.4.14

## Zweck
Korrektur zweier sichtbarer Responsive- und Footer-Probleme.

## Behoben
- Die Überschrift „Datenschutzerklärung“ bleibt auf kleinen Mobilgeräten vollständig innerhalb der Kachel.
- Der Desktop-Footer bildet eine kompaktere Einheit.
- Der gelbe Trennstrich zwischen den beiden Footer-Bereichen wurde entfernt.

## Unverändert
- Inhalte der rechtlichen Seiten
- Mobile Footer-Anordnung
- Grid
- Kachelgrößen
- Navigation
- JavaScript
- JSON-Daten
