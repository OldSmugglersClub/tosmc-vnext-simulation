# Release Notes – Version 3.1

## Administrations- und Wartungszentrum

Version 3.1 ergänzt eine eigenständige, ausschließlich lesende Kontrollseite `admin.html`.

Funktionen:
- Anzeige von Website-, Schema- und Datenversion
- Live-Prüfung aller registrierten JSON-Kernquellen
- Status, Detailangabe und Ladezeit je Datenquelle
- erneute Prüfung ohne Seitenneuladen
- Download eines vollständigen Systemberichts als JSON
- direkter Zugang aus dem Wartungspanel der Wettbewerbsseiten

Das freigegebene Grundlayout, die Kachelgrößen, Abstände und die bestehende Navigation wurden nicht verändert.
