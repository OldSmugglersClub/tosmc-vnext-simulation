# Release Notes – Version 4.5.2

## Wertungsregeln
- Ergebnis: 5 Punkte
- Tordifferenz: 3 Punkte
- Tendenz: 2 Punkte
- Remis ohne exaktes Ergebnis: 3 Punkte
- falsche Tendenz: 0 Punkte

Gewertet wird das offizielle Ergebnis nach 90 Minuten einschließlich Nachspielzeit, ohne Verlängerung und Elfmeterschießen.
