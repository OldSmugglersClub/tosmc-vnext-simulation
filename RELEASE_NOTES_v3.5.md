# Release Notes 3.5

Version 3.5 ergänzt das Administrationszentrum um einen sicheren, vollständig lokalen Prüfablauf für JSON-Datensicherungen. Die Sicherungsdatei wird im Browser analysiert. Fehler, fehlende registrierte Quellen und unbekannte Dateien werden ausgewiesen. Bei bestandener Prüfung kann ein Importplan als JSON heruntergeladen werden.

Die statische Website kann GitHub-Dateien nicht selbst überschreiben. Die Wiederherstellung bleibt daher bewusst ein kontrollierter manueller Vorgang.
