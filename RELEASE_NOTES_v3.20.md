# Release Notes – Version 3.20

## Ranglistenverlauf und Formkurve

Version 3.20 ergänzt eine zentrale Verlaufsanalyse für Teilnehmer. Punkte und Platzierungen werden über die erfassten Spieltage kumuliert. Wettbewerbe können getrennt betrachtet und zwei Teilnehmer direkt verglichen werden. Der Formwert basiert auf dem Durchschnitt der letzten fünf Wertungsabschnitte.

Das freigegebene öffentliche Layout wurde nicht verändert.
