# Release Notes 3.24

## Erinnerungsprotokoll

Version 3.24 ergänzt eine lokale Verwaltungsseite für den nachvollziehbaren Versand von Abgabe-Erinnerungen. Offene Erinnerungsfälle werden aus den zentralen Spiel-, Teilnehmer- und Tippdaten ermittelt. Manuell versendete Erinnerungen können mit Zeitpunkt, Kanal und Bearbeiter protokolliert und anschließend als zentrale JSON-Datei oder CSV exportiert werden.

Es findet weder ein automatischer Versand noch eine automatische Änderung des GitHub-Repositories statt. Das öffentliche Layout und bestehende Kachelgrößen bleiben unverändert.
